DESCRIÇÃO
---------
Servidor MCP (Model Context Protocol) que conecta o Claude Code ao app TradingView Desktop
(via Chrome DevTools Protocol) para análise automatizada de gráficos. Tudo roda LOCALMENTE
— nenhum dado do TradingView sai da máquina. Exige assinatura válida do TradingView (não
burla paywall; apenas lê/controla o app já rodando).

O QUE O FORK "JACKSON" ADICIONA (sobre o original)
---------------------------------------------------
- morning_brief: um comando que varre a watchlist, lê todos os indicadores e retorna dados
  estruturados para o Claude gerar o "bias" da sessão
- session_save / session_get: salva o brief diário em ~/.tradingview-mcp/sessions/ (compara
  hoje vs ontem)
- rules.json: regras de trading escritas uma vez (critérios de bias, risco, watchlist),
  aplicadas automaticamente no morning brief
- Correção do tv_launch para TradingView Desktop v2.14+
- CLI "tv brief" (rodar o morning brief pelo terminal)

ARQUITETURA (3 camadas) — pasta src/
-------------------------------------
src/server.js        → ponto de entrada do servidor MCP
src/connection.js    → conexão com o TradingView via Chrome DevTools Protocol
src/core/            → LÓGICA de cada domínio (chart, data, indicators, drawing, replay,
                       alerts, morning, watchlist, pine, ui, pane, tab, capture, stream...)
src/tools/           → DEFINIÇÕES das ferramentas MCP (o que o Claude enxerga) — espelha core/
src/cli/commands/    → INTERFACE de terminal (mesmos domínios como subcomandos do "tv")
